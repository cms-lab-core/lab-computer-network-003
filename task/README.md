# Ethernet: как выглядит кадр

Два Linux/netshoot-хоста соединены напрямую через `eth1`.

В работе студент:
- видит фиксированные MAC-адреса обоих интерфейсов;
- настраивает IPv4 только для генерации полезного L2-трафика;
- фиксирует neighbor mapping, чтобы ARP не отвлекал от темы Ethernet;
- предсказывает поля Ethernet II header;
- подтверждает их реальным `%%capture_traffic` и hex dump;
- проходит CHECK рабочего состояния;
- намеренно подменяет destination MAC mapping;
- наблюдает, что link/IP/route остаются исправными, а доставка ломается;
- восстанавливает корректный MAC mapping и проходит финальный CHECK.

`eth0` — management plane платформы. Его не изменяем.
